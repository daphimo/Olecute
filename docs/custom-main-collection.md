# Collection and shared product listings

The default collection template now uses `custom-main-collection`. The former title/description section is retained but disabled to avoid duplicate headings. Alternate templates using `main-collection` retain their layout and also render the shared card.

In the collection section, choose Pagination or Infinite loading, products per page (8?48), desktop columns, filters, and subcollection navigation. Add a `custom.sub_collections` metafield of type **List of collections** to populate the pills. Missing references are skipped. Configure the available storefront filters in Shopify admin; labels, counts, disabled/selected values and native remove URLs come from Shopify's `collection.filters` and filtered `collection.products_count`.

Filtering follows Shopify's filter objects and URL contract: https://shopify.dev/docs/api/liquid/objects/filter and https://shopify.dev/docs/storefronts/themes/navigation-search/filtering/storefront-filtering/support-storefront-filtering . Price inputs submit decimal currency amounts using the server's cent values divided by 100.

The GET form and pagination work without JavaScript. With JavaScript the same filter panel moves into a native modal using the theme's shared scroll-lock utilities. Apply and sorting request the section, update products/count/active filters/navigation and push the URL; Back/Forward requests the corresponding state. Filters use Apply so several selections can be made together. Independent query parameters are preserved during AJAX Apply/Clear. Infinite loading observes the next-page link 600px early, appends unique product IDs, prevents duplicate/concurrent requests and stops at the final page. It keeps the filtered URL rather than changing it for every appended batch. Errors retain current products and show retry; there is always a next-page link before enhancement.

`custom-product-card` is shared by collection, search, related/complementary recommendation sections and blocks, and recently viewed/predictive product lists. Existing AJAX search/recommendation components, wrappers and pagination hooks remain. The old aspect-ratio helper is optional because the custom card handles its own sizing. The compact header predictive section remains image/title-only as required by the separate header design. Shared card settings, quick add, galleries and wishlist behavior remain in the existing commerce system; AJAX collection renders do not install duplicate event handlers.
